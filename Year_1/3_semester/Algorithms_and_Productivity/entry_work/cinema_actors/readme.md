# Программное приложение «Киноактеры»

Консольное приложение для работы со списком киноактеров
(лабораторная работа №1, вариант 10).

## Возможности (пункты меню)
1. Вывод всех актеров в виде таблицы.
2. Выход из программы.
3. Добавление нового актера (фамилия, имя, количество фильмов, гонорар в млн $).
4. Удаление актера по его номеру в таблице.
5. Сортировка по выбранному свойству (фамилия / имя / фильмы / гонорар).
6. Фильтр: актеры, чей гонорар не менее указанного значения.
7. Вывод гонораров всех актеров в Евро (курс -- константа EURO_RATE в manager.py).

## Ограничения
- Список хранит не более N_MAX = 12 элементов (константа в models.py).
- При запуске в списке уже есть 5 демо-актеров (hard-code в main.py).

## Структура проекта
- models.py  -- классы Actor и ListOfActors: данные, добавление/удаление с проверками.
- manager.py -- сортировка, фильтрация, перевод гонорара в Евро.
- ui.py      -- консольное меню и ввод данных с проверкой.
- main.py    -- точка входа, демо-данные.

## Запуск
```
python main.py
```

Требования: Python 3.9+, сторонних зависимостей нет.
