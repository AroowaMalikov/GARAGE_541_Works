**ЛАБОРАТОРНАЯ РАБОТА 1**
**Реализация CRUD-операций произвольным способом**

**Задание**

Разработайте программное приложение с произвольным интерфейсом (консоль, веб, мобильное, чат-бот и пр.) для работы со списком объектов согласно своему варианту. Объект характеризуется 4 свойствами (свойства перечислены в варианте).

Используемая структура данных должна вмещать не более N_MAX = 12 элементов. При попытке добавить (N_MAX+1)-ый элемент сообщить о невозможности это сделать. Аналогично, при попытке удалить элемент, если структура данных уже пуста, тоже сообщить о невозможности это сделать.

При запуске программы уже должно содержаться 5 демо-объектов, добавленных предварительно в программном коде (hard-code, скрипт и пр.).

**Приложение предполагает работу меню из следующих пунктов:**
1. Вывод всех объектов в виде таблицы.
2. Выход из программы.
3. Добавление нового объекта (значения свойств вводит пользователь).
4. Удаление выбранного пользователем объекта (механизм выбора удаляемого элемента – на усмотрение студента).
5. Сортировка объектов по выбранному пользователем свойству (механизм выбора поля сортировки – на усмотрение студента).
6. Фильтрация (вывод объектов с указанным свойством) – **согласно варианту**.
7. Преобразование значения свойства у всех объектов – **согласно варианту**.

**Таблица варианта:**

| Номер варианта | 10 |
| :--- | :--- |

| **Свойство 1** | Фамилия (строка) |
| **Свойство 2** | Имя (строка) |
| **Свойство 3** | Количество фильмов (целое число) |
| **Свойство 4** | Суммарный гонорар в млн. долл. (вещественное число, 2 знака после занятой) |
